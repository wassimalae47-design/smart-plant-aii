# Smart Plant AI — دليل النباتات الذكي

واجهة أولية عربية (RTL) كتطبيق ويب تقدمي PWA قابل للتثبيت على Android بعد نشره عبر HTTPS.

## ما يعمل في هذه النسخة
- واجهة عربية متجاوبة مع الهاتف.
- اختيار صورة من المعرض أو فتح الكاميرا الخلفية عبر متصفح الهاتف.
- معاينة الصورة المختارة.
- manifest وservice worker للتثبيت والتخزين المؤقت الأساسي.

## ما لم يُنفّذ بعد
- لا يوجد اتصال فعلي بخدمة التعرف على النباتات.
- لا توجد قاعدة بيانات نباتية أو صفحة نتائج حقيقية بعد.
- زر التعرف معطّل عمداً حتى لا يعطي التطبيق نتائج وهمية.

## النشر من الهاتف
1. أنشئ مستودع GitHub باسم `smart-plant-ai`.
2. فك ضغط ملف ZIP على الهاتف.
3. ارفع الملفات الموجودة داخل المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
4. من إعدادات المستودع افتح Pages، واختر النشر من الفرع `main` والمجلد `/(root)` ثم احفظ.
5. بعد ظهور رابط Pages افتحه في Chrome على Android، ثم اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إذا ظهر الخيار.

## المرحلة التالية
إضافة وسيط خلفي آمن (backend) يتصل بخدمة تعريف نباتات مثل Pl@ntNet. لا تضع مفتاح API في ملفات الواجهة أو داخل تطبيق Android؛ يجب حفظه في الخادم.

## السلامة
نتيجة التعرف احتمالية وليست تشخيصاً مؤكداً. لا تستخدمها وحدها لتحديد صلاحية النبات للأكل أو العلاج. يجب توثيق الفوائد التقليدية منفصلة عن الأدلة العلمية، مع ذكر السمية والتداخلات وموانع الاستعمال ومراجع موثوقة.
