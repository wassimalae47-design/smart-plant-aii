# Smart Plant AI
واجهة ويب عربية قابلة للتثبيت على الهاتف (PWA) + Cloudflare Worker للاتصال بـ Gemini.

## 1) نشر خدمة التعرف
1. أنشئ Worker في Cloudflare.
2. استبدل محتوى ملف Worker بمحتوى `src/index.js` (أو انشر المشروع باستخدام Wrangler).
3. في إعدادات Worker أضف Secret باسم `GEMINI_API_KEY` وضع مفتاح Gemini فيه. لا تضع المفتاح في `index.html` ولا تشاركه.
4. انشر Worker وانسخ عنوانه الذي ينتهي بـ `workers.dev`.

## 2) تشغيل الواجهة
ارفع ملفات المشروع إلى استضافة صفحات ثابتة مثل Cloudflare Pages أو GitHub Pages. افتح الموقع، وضع رابط Worker في خانة رابط خدمة التعرف.

## تنبيه
التعرف احتمالي. لا تستخدم النتيجة لإثبات أن النبات صالح للأكل أو العلاج. الاستخدامات التقليدية منفصلة عن الاستخدامات المدعومة علمياً.
